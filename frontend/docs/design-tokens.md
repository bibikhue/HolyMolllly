# 디자인 기본값

글꼴과 UI 텍스트의 색·크기, 모서리, 그림자는 `src/index.css`의 변수를 사용한다. 국가·히트맵 등 차트 데이터 색은 각 데이터의 색 규칙을 따른다.

## 글꼴

| 항목 | 값 | 쓰임 |
|---|---|---|
| 기본 글꼴 | `"Pretendard Variable", Pretendard, -apple-system, "Apple SD Gothic Neo", "Malgun Gothic", sans-serif` | 사이트 전체. `pretendard` 패키지의 variable dynamic subset을 프로젝트에서 불러온다. |
| 숫자 자릿수 | `font-variant-numeric: tabular-nums` | KPI 숫자, 표의 숫자 열, 차트 눈금. |

## 글자 크기

| 변수 | 값 | 역할 |
|---|---:|---|
| `--fs-xs` | 12px | 출처, 차트 축 눈금, 배지의 최소 크기 |
| `--fs-sm` | 13px | 카드 보조 설명, 툴팁, 짧은 보조 표기 |
| `--fs-md` | 14px | 표 본문, 버튼, 탭, 드롭다운, 입력칸, 차트 범례, KPI 단위 |
| `--fs-base` | 16px | 카드 제목과 라벨, 본문 문장, 요약 문단, 안내 문구 |
| `--fs-lg` | 18px | 기존 강조 문구와 장식 글자 |
| `--fs-section-mobile` | 20px | 720px 이하의 섹션 제목 |
| `--fs-xl` | 22px | 섹션 제목(h2) |
| `--fs-2xl` | 28px | 페이지 제목(h1), 720px 이하 KPI 큰 숫자 |
| `--fs-3xl` | 36px | 721px 이상 KPI 큰 숫자 |

KPI의 단위(명, 원 등)는 `--fs-md`를 사용한다. 정보 아이콘·화살표의 크기는 텍스트 역할과 구분한다.

## 글자색과 상태색

| 변수 | 값 | 쓰임 | 흰 배경 대비 |
|---|---|---|---:|
| `--text-strong` | `#12324A` | 제목, 주요 숫자 | 13.28:1 |
| `--text` | `#2E4A60` | 본문 | 9.27:1 |
| `--text-muted` | `#4F6577` | 보조 설명 | 6.07:1 |
| `--accent` | `#0068A9` | 링크, 선택 상태, 강조 | 5.91:1 |
| `--color-demo` | `#6F6128` | 노란 예시 자료 배지와 안내 글자 | 6.15:1 |
| `--color-up` | `#0068A9` | 방문객·소비 증가 표시 | 5.91:1 |
| `--color-down` | `#835417` | 방문객·소비 감소 표시 | 6.47:1 |

`--tint` 위 대비는 순서대로 `--text-strong` 11.69:1, `--text` 8.16:1, `--text-muted` 5.34:1, `--accent`·`--color-up` 5.20:1, `--color-down` 5.70:1이다. `--color-demo`는 현재 노란 배지 배경(`#EFECCF`)에서 5.14:1, 안내 배경(`#FAF9EF`)에서 5.81:1이다. 증감 표시는 색과 함께 ↑↓ 및 +/− 기호를 유지한다.

## 화면 배경

| 변수 | 값 | 쓰임 |
|---|---|---|
| `--surface` | `#F3F6FA` | 페이지 배경 |
| `--surface-alt` | `#F7FAFC` | 중립 내부 면과 정보 띠 |
| `--tint` | `#E8F2F8` | 선택된 섹션 링크와 파란 안내 면 |

카드 본체의 흰색과 경고 배경, hover, 차트 트랙·범례·데이터 색, 히트맵 색은 이 배경 변수의 일괄 치환 대상이 아니다.

## 모서리와 그림자

| 변수 | 값 | 쓰임 |
|---|---|---|
| `--radius-sm` | 6px | 버튼, 입력칸, 작은 배지 |
| `--radius-md` | 10px | 카드, 패널 |
| `--radius-pill` | 999px | 알약 모양 배지와 토글 |
| `--shadow-card` | `0 8px 24px rgba(19, 62, 91, .12)` | 카드와 드롭다운 그림자 |

원형 아이콘과 차트 마커는 `border-radius: 50%`를 유지한다.
