# 관광수요 전망 결과 CSV 양식

현재 화면의 M1(Seasonal naive)은 `visitorDemo.js`의 예시 방문객 수로 자동 계산합니다. 이 문서의 수치 예시는 실제 화면에서 생성된 M1 행이며, 분석팀의 결과를 대신하는 값이 아닙니다. 배포용 CSV에는 **M2~M8 결과 행만** 넣습니다. M1 행을 다시 넣으면 중복으로 거부됩니다.

## 저장 위치와 파일명

- `public/data/forecast/forecasts.csv`: 향후 1~12개월 예측값과 80%·95% 범위
- `public/data/forecast/backtest.csv`: 롤링 원점 검증의 예측값과 실제값
- `public/data/forecast/accuracy.csv`: 모형·국가·예측 기간별 집계 지표

파일명은 고정합니다. UTF-8 CSV, 쉼표 구분, 첫 행의 컬럼명과 순서를 아래와 정확히 맞춥니다. 월은 `YYYY-MM`, 수치는 천 단위 구분 기호 없이 정수 또는 소수점 표기, 비어 있는 `dm_pvalue_vs_m1`만 빈 칸으로 저장합니다. 빈 파일 대신 컬럼명만 있는 파일은 허용합니다. 페이지를 새로 열면 세 파일을 읽고 자동 생성한 M1 행에 CSV 행을 합칩니다.

현재 방문객 원자료의 최종월은 `2025-12`입니다. 이 원자료를 사용하는 동안 `forecasts.csv`의 `origin_month`도 `2025-12`여야 합니다. 실제 원자료의 최종월이 바뀌면 방문객 데이터와 CSV의 기준월을 함께 갱신합니다.

`country_code`는 `ALL`(부산 전체), `JP`(일본), `CN`(중국), `TW`(대만), `US`(미국), `HK`(홍콩), `ETC`(기타) 중 하나입니다. 모형 코드는 `M1` 기준선, `M2` SARIMA·ETS, `M3` SARIMAX, `M4` 패널 ADL 경제변수, `M5` 패널 ADL 통합, `M6` 하향식, `M7` LightGBM, `M8` 단순평균 결합입니다. 국가와 모형은 화면의 목록과 표에서 데이터에 따라 표시됩니다.

## 1. forecasts.csv

한 행은 **예측 기준월 × 대상월 × 국가 × 모형**입니다. `horizon`은 기준월에서 대상월까지의 개월 수(1~12)입니다. `forecast`와 네 범위 값의 단위는 명입니다. `lower_95 ≤ lower_80 ≤ upper_80 ≤ upper_95`를 지켜야 합니다. 과거 편향 때문에 점 예측값이 범위 밖에 있을 수 있으므로 점 예측값을 범위 안으로 강제로 옮기지 않습니다.

| 컬럼 | 뜻 |
| --- | --- |
| `origin_month` | 마지막 실제 방문객 자료가 있는 예측 기준월 |
| `target_month` | 예측 대상 월 (`origin_month`에서 `horizon`개월 뒤) |
| `horizon` | 예측 기간, 정수 1~12 |
| `country_code` | 부산 전체 또는 출발 국가 코드 |
| `model` | 모형 코드 M1~M8 |
| `forecast` | 점 예측 방문객 수 |
| `lower_80`, `upper_80` | 80% 예측 범위 하한·상한 |
| `lower_95`, `upper_95` | 95% 예측 범위 하한·상한 |

다음은 화면에서 계산된 M1 예시 3행입니다. M1은 자동 생성되므로 실제 CSV에 복사하지 않습니다.

```csv
origin_month,target_month,horizon,country_code,model,forecast,lower_80,upper_80,lower_95,upper_95
2025-12,2026-01,1,ALL,M1,230900,299771,319115,299721,319132
2025-12,2026-01,1,JP,M1,77912,95015,114510,93279,116524
2025-12,2026-02,2,ALL,M1,247900,321841,342612,321787,342629
```

## 2. backtest.csv

한 행은 **과거 예측 기준월 × 검증 대상월 × 국가 × 모형**의 롤링 원점 검증 사례입니다. `origin_month`까지의 자료만 사용해 예측해야 합니다. `actual`은 검증 대상월의 사후 실제 방문객 수입니다. 같은 `model`, `country_code`, `horizon`의 행을 모아 예측 범위의 경험적 분위수와 편향을 계산하므로 개별 검증 사례를 생략하지 않습니다.

| 컬럼 | 뜻 |
| --- | --- |
| `origin_month` | 해당 검증에서 마지막으로 사용한 실제값 월 |
| `target_month` | 검증 대상 월 |
| `horizon` | 기준월과 대상월 간 개월 수, 정수 1~12 |
| `country_code` | `ALL`, `JP`, `CN`, `TW`, `US`, `HK`, `ETC` |
| `model` | 예측에 사용한 모형 코드 |
| `forecast` | 그 기준월에서 만든 당시 예측 방문객 수 |
| `actual` | 대상월의 실제 방문객 수 |

```csv
origin_month,target_month,horizon,country_code,model,forecast,actual
2024-01,2024-02,1,ALL,M1,138200,190900
2024-01,2024-02,1,JP,M1,44291,64357
2024-01,2024-03,2,ALL,M1,161300,222800
```

## 3. accuracy.csv

한 행은 **모형 × 국가 × 예측 기간 × 검증 대상 기간**의 집계입니다. `n`은 같은 조건의 `backtest.csv` 검증 사례 수와 일치해야 합니다. `mape`는 백분율 수치(예: `25.2`는 25.2%), `rmse`는 명, `mase`는 단위 없는 비율입니다. `dm_pvalue_vs_m1`은 분석팀이 계산한 M1 대비 Diebold–Mariano 검정 p값(0~1)이며 M1은 빈 칸으로 둡니다.

| 컬럼 | 뜻 |
| --- | --- |
| `model`, `country_code`, `horizon` | 모형, 국가, 예측 기간 |
| `test_start`, `test_end` | 검증 대상월의 시작·끝 (`YYYY-MM`) |
| `n` | 해당 조건의 검증 사례 수 |
| `mape` | 평균 절대 백분율 오차, `%` 수치 |
| `rmse` | 평균 제곱근 오차, 명 |
| `mase` | 평균 절대 계절성 척도 오차 |
| `dm_pvalue_vs_m1` | M1 대비 Diebold–Mariano 검정 p값; M1은 공란 |

```csv
model,country_code,horizon,test_start,test_end,n,mape,rmse,mase,dm_pvalue_vs_m1
M1,ALL,1,2024-02,2025-12,23,25.203278,74019.216071,1.122749,
M1,JP,1,2024-02,2025-12,23,25.204316,24090.234136,1.110436,
M1,ALL,3,2024-04,2025-12,21,24.974576,75420.686817,1.164686,
```

## 계산과 반영 시 주의사항

- M1의 점 예측은 대상월의 **12개월 전 같은 달 실제값**입니다. 12개월 이내에서는 예측 기간이 달라도 같은 대상월의 M1 점 예측은 같습니다.
- 현재 M1의 롤링 원점은 `2024-01` 이후입니다. MASE 분모는 **각 기준월까지**의 월별 전년 동월 차이 절댓값 평균으로 계산합니다. 훈련 구간 이후의 값을 분모에 사용하지 않습니다.
- M1 예측 범위는 같은 국가·`horizon`의 backtest에서 `(actual ÷ forecast − 1)`을 구해 경험적 10·90 분위(80%)와 2.5·97.5 분위(95%)를 점 예측값에 곱합니다. 분위수는 정렬값 사이의 선형 보간을 사용합니다. 검증 사례가 30건 미만이면 화면에 범위 불안정 안내가 표시됩니다.
- 편향은 같은 backtest의 `(actual ÷ forecast − 1)` 평균입니다. MAPE는 `|actual − forecast| ÷ actual`의 평균에 100을 곱합니다. 0인 실제값이나 예측값은 이 계산에 사용할 수 없으므로 원자료 단계에서 확인합니다.
- 화면의 **M1 대비 개선율**은 `1 − 선택 모형 MAPE ÷ M1 MAPE`입니다. 같은 국가·예측 기간·검증 시작·종료·사례 수의 M1 행이 없으면 비교하지 않습니다. p값이나 개선율만으로 특정 모형이 가장 좋다고 단정하지 않습니다.
- 분석팀 파일의 `forecasts.csv`에는 현재 원자료 기준월의 12개 대상월과 80%·95% 범위를 모두 넣습니다. 검증 그래프와 오차 상·하위 월을 보여주려면 대응하는 `backtest.csv` 행도 필요합니다. 집계 `accuracy.csv`의 `n`·기간은 backtest 행과 맞아야 합니다.
- `visitorDemo.js`가 예시 자료인 동안은 다른 모형의 CSV를 추가해도 화면에 **예시 자료** 배지를 유지합니다. 실제 자료로 전환할 때는 원자료의 정의·국가 코드·기준월을 함께 맞춘 뒤 검증합니다.
