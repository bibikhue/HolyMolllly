# 개발 환경

```bash
# fronend로 이동
cd frontend

# 패키지 설치
npm install

# frontend 실행
npm run dev
```

```bash
# 가상환경 생성
conda create -f environment.yml

# 가상환경 업데이트
conda env update -n rise_team_1 -f environment.yml

# 가상환경 활성화
conda activate rise_team_1

# backend 경로 이동
cd backend

# backend 실행
python main.py
```
